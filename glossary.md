# Glossary

**Applied effect** — an effect from the
Effect menu that rewrites the selected
audio. Contrasts with the live effect
stack. (Chapter 7.)

**Autosave** — the recovery copy
Audacity keeps of unsaved work; a table
inside the project database while the
project is open, a temp file for
unnamed work. (Chapter 11.)

**Clipping** — distortion caused when
sound exceeds the loudest recordable
level (0 dB) and its peaks are cut off
flat. Preventable at recording time,
not repairable afterwards. (Chapters 5,
8.)

**Clip** — one continuous stretch of
audio on a track; can be moved,
trimmed, split and joined without
affecting its neighbours. (Chapter 2.)

**dB (decibel)** — the logarithmic unit
of loudness ratios used throughout
audio. 0 dB is the maximum a digital
file can hold; speech is usually worked
on well below it. Doubling power is
+3 dB. (Chapters 5, 8.)

**DC offset** — a constant shift of the
whole waveform away from zero, a
recording fault that wastes headroom.
Normalize's "remove DC offset" fixes
it. (Chapter 7.)

**Envelope** — a drawn line on a clip
that bends its volume over time
without rewriting the samples.
(Chapter 6.)

**Export** — mixing a project down to
a finished audio file (WAV, MP3, …).
The export is not the project.
(Chapters 1, 9.)

**Effect stack** — the per-track list
of effects that run live on playback
and at export, adjustable or removable
at any time. (Chapter 7.)

**Label** — a named marker on a label
track, attached to a time point or a
stretch; used for navigation and for
split exports. (Chapter 6.)

**LUFS** — loudness measured the way
ears and broadcast rules judge it, as
opposed to raw peak. Podcast and
streaming targets are written in LUFS.
(Chapters 7, 12.)

**Macro** — a saved chain of commands,
in a plain-text file, run on a project
from the window; Audacity's batch tool.
(Chapter 10.)

**mod-script-pipe** — the optional
module that exposes Audacity's command
set over two named pipes, so another
program can drive it. (Chapter 10.)

**Noise gate** — an effect that passes
sound above a chosen level and quiets
everything below it. (Chapter 8.)

**Noise profile** — the description of
a recording's steady noise, captured
from a noise-only stretch, that noise
reduction uses to clean the rest.
(Chapter 8.)

**Normalize** — an effect that raises
(or lowers) audio so its loudest peak,
or its measured loudness, equals a
chosen target. (Chapter 7.)

**Nyquist** — the audio programming
language built into Audacity; many
bundled effects are written in it.
(Chapter 10.)

**Overdub** — recording a new track
while hearing the existing ones, as
when adding a late part to a session.
(Chapter 5.)

**Peak** — the loudest single sample.
Normalize's usual target; not the same
as loudness. (Chapters 7, 10.)

**Project** — your workbench: tracks,
clips and edits in one `.aup3` file.
Nothing but Audacity opens it.
(Chapters 1, 11.)

**RMS** — a level measurement close to
average loudness, used in this guide's
lab tables and in effects like loudness
normalization. (Chapter 8.)

**Sample rate** — how many snapshots
per second a recording holds: 44,100
Hz for CD, 48,000 Hz for video work.
(Chapter 2.)

**Selection** — the stretch of time
(and tracks) commands act on. If an
edit surprises you, suspect the
selection first. (Chapter 2.)

**Spectrogram** — the waveform's other
drawing: frequency over time, loudness
as brightness. Noise has shapes in it.
(Chapters 2, 8.)

**Track** — one parallel stream of
audio in a project, playing together
with the others and mixing at export.
(Chapter 2.)
