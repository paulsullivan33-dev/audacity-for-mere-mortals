An honest footnote: the first normalize
call used parameter names from memory
(NormalizeTo, Apply) which this build
does not have; unknown parameters are
ignored, so the effect ran on its
defaults — which are PeakLevel -1 dB,
apply gain, remove DC offset — and the
measurement above is that defaults run.
To prove the parameters themselves work,
the run was repeated with the parameter
names from the build's own catalogue
(t02):

>>> Normalize: PeakLevel=-3 ApplyGain=1
    RemoveDcOffset=1 StereoIndependent=0
>>> Export2: Filename=".../out/normalized-3db.wav"

$ sox out/normalized-3db.wav -n stat
Maximum amplitude:     0.708069
(expected for -3 dB: 0.707946)
